# Books to Scrape — парсер каталога книг

## Цель проекта

Учебный проект по веб-скрапингу демонстрационного каталога
[Books to Scrape](https://books.toscrape.com/). Скрипт `scraper.py`
объединяет решения первых трёх задач:

1. **Данные об одной книге** — функция `get_book_data` извлекает
   название, цену, рейтинг, наличие, описание и таблицу
   Product Information со страницы книги.
2. **Данные обо всех книгах** — функция `scrape_books` обходит
   страницы каталога до первой 404, парсит каждую книгу и при
   необходимости сохраняет результат в `artifacts/books_data.txt`.
3. **Ежедневный запуск** — встроенный планировщик на `schedule`
   запускает `scrape_books(is_save=True)` каждый день в 19:00.

## Структура проекта

```
project/
├── scraper.py            # весь код: парсинг + планировщик
├── artifacts/
│   └── books_data.txt    # результат сбора (JSON Lines)
└── README.md
```

> Папку `artifacts/` нужно создать заранее — скрипт её не создаёт
> автоматически:
>
> ```bash
> mkdir -p artifacts
> ```

## Запуск

### 1. Данные об одной книге

```python
from scraper import get_book_data

url = (
    "http://books.toscrape.com/catalogue/"
    "a-light-in-the-attic_1000/index.html"
)
print(get_book_data(url))
```

Возвращает словарь с ключами `title`, `price`, `rating`,
`availability`, `description`, `product_information`.
При недоступной странице (не 200) возвращает **строку** с текстом
ошибки, а не словарь.

### 2. Сбор данных обо всех книгах

```python
from scraper import scrape_books

# Собрать и сохранить в artifacts/books_data.txt
books = scrape_books(is_save=True)

# Собрать без сохранения
books = scrape_books(is_save=False)
```

Проход по каталогу продолжается, пока очередная страница
`page-{N}.html` не вернёт 404.

### 3. Ежедневный запуск в 19:00

Планировщик уже встроен в `scraper.py` и запускается при импорте
модуля. Просто выполните:

```bash
python scraper.py
```

Скрипт работает в бесконечном цикле: раз в 30 секунд проверяет
расписание и в 19:00 вызывает `scrape_books(is_save=True)`.
Процесс должен работать непрерывно — не закрывайте терминал.
Чтобы остановить, нажмите `Ctrl+C`.

## Формат результата

Файл `artifacts/books_data.txt` — **JSON Lines**: каждая строка
содержит один JSON-объект с данными книги.

```
{"title": "A Light in the Attic", "price": "£51.77", "rating": "Three", ...}
{"title": "Tipping the Velvet", "price": "£53.74", "rating": "One", ...}
...
```

Такой формат удобно читать построчно:

```python
import json

with open("artifacts/books_data.txt", encoding="utf-8") as file:
    books = [json.loads(line) for line in file]
print(len(books), "книг")
```

> Если какая-то страница книги не загрузилась, в списке рядом
> с JSON-объектами окажется строка с текстом ошибки — при разборе
> файла это стоит учитывать (например, пропускать строки, которые
> не начинаются с `{`).

## Используемые библиотеки

| Библиотека       | Назначение                                      |
|------------------|-------------------------------------------------|
| `requests`       | HTTP-запросы к страницам сайта                  |
| `beautifulsoup4` | Парсинг HTML и извлечение данных                |
| `schedule`       | Планирование ежедневного запуска в 19:00        |

Стандартные модули `time` и `json` устанавливать не нужно.

## Примечания

- Books to Scrape — демонстрационный сайт: цены и рейтинги
  случайны и не имеют реального смысла.
- Планировщик срабатывает по **локальному времени** машины,
  на которой запущен скрипт. Убедитесь, что системные часы
  настроены верно.
- Если планировщик должен работать в облаке (например, на сервере
  или в GitHub Actions), а не на локальном компьютере, время
  в cron-расписании указывается в UTC.
- Полный проход по каталогу — около 1000 запросов и может занимать
  несколько минут в зависимости от скорости сети.
